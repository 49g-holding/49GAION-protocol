# 49GAION Operating Protocol v1.5.0

Approved by the governing seat (GOV) of 49GAION. Decisions: [`DR-0006`](https://github.com/49g-holding/49GAION/blob/main/decisions/DR-0006-decision-record-lock.md) (decision records frozen; how a change reaches main) and [`DR-0007`](https://github.com/49g-holding/49GAION/blob/main/decisions/DR-0007-49gaion-v1-5-0-structure-accountability-signatures.md) (structure, accountability, signatures, gateway and register).

## Summary

- Unit card, Port card, Work Item, signature record and process record schemas changed to match the Standard v1.5.0.
- Library v3 cards, including bot cards with a credential, a cell kind and a rule that a bot never signs.
- Signature records bound to the payload hash, the executor, a single-use nonce and an expiry; records and logs hold no personal data.
- Reference organisations are required, and each cited Human Floor item must exist.
- Signature fixture sets for dual signature, never-held types, self-signing and the entity rule, with a fixture log in every card-schema-test run.

## Checks on main

Required checks gain github-separation, ci-selftest and fixture-orgs. The no-org-names check also judges added or changed lines against a private list of person names, reporting path and line only and failing closed.

## Known limits

- The person-name check proves its given-name variant forms only through fictional selftest cases; no run on real text exercises those forms.
