# Source keys used by the 49GAION Standard

The Standard cites the pilot organisation's source documents by neutral keys, so that the normative text names no organisation. The documents themselves, and what each key resolves to, are held privately by the pilot organisation and are not part of this repository.

| Key | Source |
|---|---|
| `SRC-CODE-PLATFORM` | pilot organisation source, held privately |
| `SRC-WRITTEN-RECORD` | pilot organisation source, held privately |
| `SRC-WR-DECISION` | pilot organisation source, held privately |
| `SRC-DECISION-RIGHTS` | pilot organisation source, held privately |
| `SRC-PANEL-SPEC` | pilot organisation source, held privately |
| `SRC-ENGINE-DOCS` | pilot organisation source, held privately |
| `SRC-IT-DR-000n` | pilot organisation source, held privately |
| `SRC-OPS-DESIGN` | pilot organisation source, held privately |
| `SRC-OPS-DR-nnnn` | pilot organisation source, held privately |
| `SRC-ENG-STD-0001` | pilot organisation source, held privately |
| `SRC-DIR-0006` | pilot organisation source, held privately |
| `SRC-FO-<TYPE>-<n>` | pilot organisation source, held privately |
| `SRC-ENGINE-P-000n` | pilot organisation source, held privately |
| `SRC-OPS-ENTRY-DESIGN-TEMPLATE` | pilot organisation source, held privately |
| `SRC-OPS SETTLED` | pilot organisation source, held privately |
| `SRC-OPS-DR-0001`, `SRC-OPS-DR-0007`, `SRC-OPS-DR-0009`, `SRC-OPS-DR-0015`, `SRC-OPS-DR-0016`, `SRC-OPS-DR-0018` | pilot organisation source, held privately |
| `SRC-FO-ROLES` | pilot organisation source, held privately |
| `SRC-IT-C-0028` | pilot organisation source, held privately |

Role phrases such as "the Top Management AIOC", "the protocol AIOC", "the IT AIOC" and "the engineering AIOC" name an AIOC by its function. "The Top Management AIOC" is an AI unit that works for Top Management; it is not `[ORG]HOAC-TM`, which is Top Management itself, a human unit, and decides.
