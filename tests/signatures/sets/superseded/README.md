# Superseded signature sets

This set was a must-fail case up to the direction of GOV of 15 October 2026. Two positions are two parties, even when one natural person occupies both (Standard §1.1, item 10; Protocol §4.10, item 13), so the case it tested no longer fails. It is kept unchanged for the record. It is no longer in the must-fail set, and `tests/cards/check_cards.py` reports it only for reading.

| Superseded set | Why | Current case |
|---|---|---|
| `must-fail-dual-one-person-two-cells.json` | It failed dual signature because one occupant signed under two Cells; two Cells are two parties and count as two | `../valid-dual-one-occupant-two-positions.json` |
