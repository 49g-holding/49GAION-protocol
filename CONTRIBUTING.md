# Contributing · 49GAION Operating Protocol

1. **Changes by pull request** with green checks, reviewed by someone other than the writer; no force-push.
2. **Current rule only.** The main text states only the rule in force.
3. **Decisions.** Decision records are kept once, in the hub ([`49GAION/decisions/`](https://github.com/49g-holding/49GAION/blob/main/decisions/README.md)); [`decisions/README.md`](decisions/README.md) links to them.
4. **Positions, not people.** Writing names positions; a person's name appears nowhere. Who holds a position is the organisation's own mechanism, outside the system (`49GAION/DR-0049`).
5. **Versions** are semantic tags, `v<major>.<minor>.<patch>`.
6. **Never invent a fact.** `NOT_RUN` is never PASS.
