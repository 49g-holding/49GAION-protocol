# Contributing · 49GAION Operating Protocol

1. **Changes by pull request** with green checks, reviewed by someone other than the writer; no force-push.
2. **Current rule only.** The main text states only the rule in force.
3. **Decisions.** A decided subject becomes a `DR-####` file in `decisions/`, listed in [`decisions/README.md`](decisions/README.md).
4. **Positions, not people.** Writing names positions; a person's name appears only in a holders register.
5. **Versions** are semantic tags, `v<major>.<minor>.<patch>`.
6. **Never invent a fact.** `NOT_RUN` is never PASS.
