# TEST-EDITION-MAKER v5 · the fixed test of 49GAION Edition Maker

The cases are those of [`PRD.md`](PRD.md), section 11. This file holds their state. Each case passes or fails on a built Edition Maker; until it is built and run, every case is `NOT_RUN`.

A light dry run of the mechanism was made by hand on 22 October 2026, on the invented sample organisation Ten ([`trials/2026-10-22-ten-light/`](trials/2026-10-22-ten-light/REPORT.md)). Its results are shown for reference; they are not the test's result.
